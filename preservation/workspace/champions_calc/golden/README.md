# ゴールデン試合と採点（reader.swift 改善計画フェーズ1）

reader の出力プロトコルを、正解ログ（人手で確定した真の対戦経過）と突き合わせて数値で測るための基盤。

- `truth/<battle>.log` — 正解ログ（reader のプロトコル方言で記述。相手側 HP は % 表記、自軍は実数）。
- `truth/<battle>.notes.md` — 正解ログの作成根拠と、到着プロトコルへの修正一覧。**正解の確定にはログ分析チャットの検証が要る**（原案の間は未確定）。
- `score_golden.py` — 採点ツール。使い方: `python3 score_golden.py truth/<battle>.log <reader出力.log> [--json results/<name>.json]`
  - ヘッダー正確さ（両軍 |poke| の集合一致と順序）
  - 行レベル（ターン区間ごとの行集合で、行種別の適合率・再現率・F1）
  - ターン整合（正解の行が同じターン区間に現れた割合／別ターン／欠落）
  - 厳密順序（副指標、LCS ベース）
- `results/` — 採点結果の JSON。
