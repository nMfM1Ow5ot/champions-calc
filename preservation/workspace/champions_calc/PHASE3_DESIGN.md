# フェーズ3 設計メモ (交代の読み取りとデフォルト帰属の作り替え)

作成: 2026-11-22、バックエンドチャット。対象 reader.swift (build 20261122_1159 時点)。
計画の柱: 「証拠と解釈の分離」「状態を点でなく幅で持つ」。

## 棚卸し結果 (現行構造)

### 交代読み取り (プレート経路が唯一の本線)
- processPlates の交代確定は「点の決定」: pendingSwitchSpecies[plate] に候補は
  1 種族だけ保持し、別種族が読めると候補・カウント・開始時刻が全て差し替わる。
  アニメーション中の交互読み (A/B/A/B) で証拠が毎回リセットされる。
- 確定条件: 同一種族 2 フレーム連続 (交代技の戻り消費後は 1 回)。
  ガード類: 同種族の相方枠在席 (switch_species_dup)、自軍の要員待ち
  (replacementBusy、20 秒安全弁)、登録受け入れ (minePlateAdmitted)。
- pendingSwitchSpecies の読み手は広い: フィールド開始の保留 (setWeather/
  setTerrain)、flush 判定、ミス/ひんし文の整合チェック、switchInFlight 系、
  デバッグ記録 (state excerpt)。データモデル変更時は全て移行が必要。
- 文経路: ゆけっ!/戻れ! 文は対戦中は原則「消費のみ」。交代の証拠として
  使われていない (実例: battle_20261122_103530 ターン3、交代文は観測
  されていたがプレート経路が登録で弾かれ、交代が落ちた)。

### デフォルト帰属
- slotFor(side, species) が既定枠 (a 枠) への吸い込み口。場に一致が無いと
  無条件で a 枠を返す。呼び手: 技告知の主経路、ランク変化 (checkBoostText)、
  メガ (103530 でラベルは実表記寄せ済みだが slotFor 自体は残る)。
- 技告知経路: 解決した種族が場におらず、空き枠 1 つの救済登録も発動しない
  場合、文は a 枠へ帰属される。default_attribution の証拠は 2 回目で初めて
  残る。コメントにあるとおり「どちらの枠が古いか文だけでは判別できない」
  ため自動登録はしない、が現行方針。
- resolvedBoostSide は両側在席時に直前の技使用者で寄せる等、証拠ベースの
  寄せが部分的にある。最終フォールバックは p1。

## 設計

### 1. 交代候補の区間モデル (プレート経路)
- pendingSwitchCandidates: [plate: [species: Candidate]] に置き換える。
  Candidate = {count, firstSeen, lastSeen}。
- 読みのたびに該当候補の count と lastSeen を更新する (別候補を読んでも
  既存候補は消えない)。占有者の再読みでは候補を即消去せず、lastSeen から
  3 秒を超えた候補を期限切れとして落とす (区間の自然な閉じ方)。
- 確定: count >= confirmReads (従来どおり 2、pivot/文証拠ありは 1) かつ
  「最も直近に読まれた候補」であること。競合時はリーダーが確定し、敗れた
  候補は証拠記録 (switch_guard 系) を残して破棄する。
- 既存ガード (同種族相方・要員待ち・受け入れ) は確定の直前に従来どおり適用。
- 読み手の移行: pendingSwitchSpecies は「現在のリーダー種族」を返す
  アクセサに置き換え、フィールド保留・整合チェック・デバッグ記録を移行する。

### 2. 文証拠の統合
- 戻れ! (離脱種族) と ゆけっ! (入場種族) の組を textSwitchEvidence として
  保持する (side, outSpecies, inSpecies, at)。離脱種族の枠が分かるため、
  プレートで入場種族がその枠に 1 回読めれば確定に進める (pivotReturnAt と
  同じ「文が先行した交代の早期確定」)。
- 技告知で解決した種族がその側の場におらず、保留中の交代候補にも無い場合、
  その種族を「側の候補」として登録し、技行は即座に既定枠へ出さず保留する。
  プレート確定でその種族が入場したら、保留した技行を交代行の直後に流す。
  ターン内に確定しなければ、証拠記録 (off_field_evidence) 付きで最も
  尤もらしい枠へ出す (現行の slotFor 既定は最終手段として残すが、無言の
  帰属は廃し、必ず証拠を残す)。

### 3. 交代とメガの形 (フェーズ1 所見)
- 検証済み真実 (battle_20261122_091721) では交代はターン5頭、メガ行は
  ターン6頭と別ターンに分かれる。pullBackSwitchBlock の引き戻し対象から
  detailschange / -mega / -item 行を外し、交代行 (+入場時 HP 補正の
  被ダメ・回復行) だけを引き戻す。メガ行は読まれたターンの区間に残る。
- ハーネス T126b が現行の引き戻し形を固定している場合は、真実の形に
  合わせて更新する (検証済み golden が根拠)。

## 実装の切り分け
1. 区間モデル + 読み手移行 (プレート経路のみ、文統合なしで挙動等価 + 交互
   読みへの耐性)。
2. 文証拠 (戻れ/ゆけっ の組と、技告知の保留・流し込み)。
3. pullBack の対象縮小。
各段でハーネステストを追加し、check_reader と全スイートを通してから push する。
