# PaddleOCR ステップ0 Mac 実測キット — 手順書

このキットは、PaddleOCR 補助チャンネルのステップ0（Mac での実測）の
ためのものです。所要時間の目安は、導入 10〜20 分（ダウンロード量に
依存します）＋実測 5〜15 分です。途中で止めても、導入スクリプトは
再実行できます。

前提：すでに古い版のキットを展開済みの場合は、先にその
`paddle_kit` フォルダを削除してから、この版を展開してください
（ファイル名が同じため、上書きでは混ざるおそれがあります）。

## 手順1：キットを展開する

1. 添付の `paddle_kit_20261123.zip` を Mac にダウンロードします。
2. Finder で ZIP をダブルクリックすると、`paddle_kit` フォルダが
   できます。置き場所は任意です（この手順ではダウンロードフォルダ
   に置いたものとして進めます）。

## 手順2：ターミナルを開き、フォルダへ移動する

1. ターミナルを開きます。Spotlight（Command＋スペース）で
   「ターミナル」と入力して Enter、でも開けます。
2. 次のコマンドを入力します（末尾のスペースまで含めます）。
   まだ Enter は押しません。

   ```bash
   cd 
   ```

3. Finder の `paddle_kit` フォルダを、ターミナルウィンドウの中へ
   ドラッグ＆ドロップします。フォルダのパスが自動で入力されます。
4. Enter を押します。
5. 次のコマンドで、移動できているか確認します。

   ```bash
   ls
   ```

   `install_on_mac.sh`、`fetch_models.py`、`measure.py`、
   `samples`、`README_MAC.md` の5つが見えれば正解です。

## 手順3：導入する（仮想環境の作成、モデルの取得、起動確認まで自動）

1. 次のコマンドを実行します。

   ```bash
   bash install_on_mac.sh
   ```

2. 処理の内容：`~/champions_paddle/.venv` に仮想環境を作り、
   paddlepaddle 3.3.1 と paddleocr 3.7.0 を入れ、small と medium の
   両モデルを取得して、それぞれ1回ずつ読み取りを実行します。
   プロジェクトのフォルダには何も入りません。
3. 完了の目印：最後に次の2行が表示されます。

   ```text
   FETCH_MODELS_DONE
   == done ==
   ```

4. 途中で `python3 --version` の結果が 3.9 より古い場合や、赤い
   エラー文で止まった場合は、それ以上進めず、手順5の方法で
   表示内容を送ってください。

## 手順4：実測する

1. 手順2と同じターミナルで、`paddle_kit` フォルダにいる状態の
   まま、次のコマンドを実行します。

   ```bash
   ~/champions_paddle/.venv/bin/python measure.py
   ```

2. 処理の内容：`samples/` の実切り出し28件（プレート18件＋
   メッセージ帯10件）を small／medium の両モデルで読みます。
   プレートは等倍と2倍拡大の両方、帯は等倍のみを測ります。
3. 完了の目印：最後に次の行が表示され、`paddle_kit` フォルダの
   中に `measure_result.jsonl` ができます。

   ```text
   MEASURE_DONE -> （パス）/measure_result.jsonl
   ```

## 手順5：結果を送る

1. `paddle_kit` フォルダの中の `measure_result.jsonl` を、
   バックエンドチャットへ添付して送ってください。
2. エラーで止まった場合は、ターミナルの表示内容をすべて選択して
   コピーし、そのままチャットへ貼ってください。

いただいた結果で、モデル（small／medium）と切り出しの拡大率を
確定します。余白は画像認識チャットの相談結果に基づき、設計文書で
確定済みです。
