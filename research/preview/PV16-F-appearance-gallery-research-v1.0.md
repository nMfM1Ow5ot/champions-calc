# PV16-F appearance gallery research v1.0
2026-11-26 JST. LIMITED_DEVELOPMENT_RESULT; independent acceptance blocked. IMRaD, GPT basic principles v1.10. Mathematics is instrumental; practical recognition, resource cost and latency are the primary evaluation criteria.

## Introduction
Improve visual separability and selective recognition instead of further tuning acceptance thresholds alone. HOG background: Dalal & Triggs (2005), https://doi.org/10.1109/CVPR.2005.177 (shape descriptor developed for human detection; no claim of transfer performance). Previous reference descriptor archive contains no original PNGs, so new image features are tested using an auxiliary observed-screen gallery, not a replacement full-catalog dictionary.

## Methods
Verified pinned source hashes, source images/video frames via existing collect(), and saved ranks; replayed all 240 slots with identical candidate ranks and type outputs. 239 evaluable, 40 screens, 29 proxy roster groups, same provisional labels as prior work (96 exact-ID, 143 base-species). Decompose winning true-reference vs best wrong-reference score into hash, hue, aspect, density, type terms; compare feature ablations/reweighting, foreground alternatives, and observed-screen gallery. 43 configurations. Exclude entire query proxy group from type and supplemental gallery. Only unambiguous ID labels enter gallery. Union foreground: largest connected component plus adjacent separated components (9x9 dilation, area>=5), normalize to 32x32 preserving aspect, gray background. HOG normalized L2 (32x32, 16x16 blocks, stride 8, cells 8, 9 bins); Lab 4x4 color layout and 4x4 foreground occupancy. Supplemental distance .5*normalized HOG L2 + .3*Lab mean absolute difference + .2*occupancy mean absolute difference. Minimum per candidate across gallery, bonus w*max(0,1-distance/.30), equivalently common additive w minus bonus. Selected w=.4 post-hoc. Absent reference or invalid foreground receives no bonus; no hard candidate exclusion. Absolute scores shift so reject rules must be refitted rather than reusing thresholds. Fit monotone distance/negative-margin/ratio5 boundary using known errors plus simulated absent-catalog negatives (delete true ID/base labels). In a focused nested audit exclude outer proxy group from BOTH local type bank and gallery for calibration rows as well as test rows; historical glyph bank, design and labels are still non-independent. No formal acceptance outputs.

## Resource benchmark
CPU x86_64 AMD EPYC 9V74, OpenCV 4.13.0 single thread, NumPy 2.3.5, precomputed local banks; one warmed pass of 240 slots. Median/p95 ms: baseline 3.148/3.606; scalar gallery only 1.765/1.970; vector gallery only .088/.128; descriptor .332/.404; baseline+descriptor+scalar 5.249/5.849; baseline+descriptor+vector 3.576/4.069. Vectorization ~20x faster for gallery scoring alone, total median +.429 ms (~13.6%) vs baseline. Timing is a sum of measured sections, excludes capture, decode, scene/geometry detection, bank preparation, final sorting of the supplemental scores, UI and temporal fusion. Max gallery numeric arrays 325064 bytes, excludes Python objects/type/base banks. Not Mac M4 or end-to-end latency.
## Discussion
Practical candidate: preserve prior ranker and add vectorized auxiliary gallery; do not replace foreground globally. Gallery coverage only 46/293 distinct IDs, post-hoc tuning, provisional labels, historical bank and correlation; independent eligible n=0. Prior-to-new calibration comparisons exploratory, simulated unknown is not real negative. No hard acceptance, no actual match win-rate estimate. Remaining work: verify gallery labels/rights, acquire missing original reference images or improve gallery coverage, test genuine unknown/negative and fresh independent battles, Mac target benchmark, fixed acceptance calibration, integration by separate approval. Stop repeated same-data threshold tuning unless it has expected practical benefit.
