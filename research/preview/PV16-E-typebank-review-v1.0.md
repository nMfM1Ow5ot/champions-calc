## Methods
Reference legacy geometry from champions_preview_features_pv01.py, adjusted fixed window relative to 128x48 slot; grayscale std<=30 -> NONE; RGB median of nonwhite pixels; 12x12 resized glyph, score .7*(1-correlation)/2+.3*RGB Euclidean/441.7, reject score>=.42; guard also rejects margin<.025 (exploratory threshold, not calibrated). RGB-only distance/441.7 reject >=.25. Hybrid preserves PV16-E 8x8 BGR nearest template trained on other four screens, threshold .18; invokes glyph or guarded glyph fallback only if nearest template rejects. No label of target screen used in fold templates. Fixed historical prototype bank may contain overlapping samples; same five known development screens used to select this approach, not independent.
