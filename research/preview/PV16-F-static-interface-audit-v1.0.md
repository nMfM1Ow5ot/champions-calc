## Findings
- SA-01 high, integration risk: propose() receives an unversioned boundary; changing gallery bonus/score scale or dictionary makes calibration incompatible. Even a common +0.4 shift preserves order and margin but changes absolute distance and ratio5. JS arithmetic pilot [0.2,0.4,0.5,0.6,0.7,0.8,0.9,1,1.1,1.2] -> d1=.2/.6, margin=.2/.2, ratio5=.285714/.545455. No Python execution. Bind boundary to exact ranker, catalog, dictionary, score kind, aggregation and sampling protocol.
- SA-02 high, integration incompatibility: fuse(plurality) emits negative vote scores, while coverage.evidence rejects negative distances. Borda also has different units and semantics. Restrict distance-based acceptance to explicitly approved score domains; separate adapters and calibrations for others. Do not translate vote ranks into distance probabilities.
- SA-03 high, integration risk: fuse checks session/frame identity but no model/dictionary/score version. Same-session mixed versions may be accepted by fusion. Require consistent immutable metadata and validated slot geometry. Exact frame ID dedup only; do not count adjacent correlated frames as independent.
- SA-04 high, latent iterator contract bug: propose uses any(...) to validate boundary, then passes same boundary to eligible. For a nonempty valid one-shot iterator, validation exhausts it; generator truthiness remains true and any(dominates...) sees no points. would_accept can be true despite an original blocking point. Materialize immutable tuple once or explicitly reject unsupported types; unit tests necessary. accepted remains false. Finding inferred from source, not executed in Python.
- SA-05 medium: encode() retries foreground extraction with modal background when initial feature fails width/area checks, but returns fallback without equivalent final quality checks. Require final validation and invalid/empty result handling; assess coverage regression before adoption.
## Proposed interface
Immutable metadata: schema_version, catalog_digest, ranker_revision, reference_digest, score_kind, aggregation_method, calibration_revision, scene/geometry_version and session/slot identity. Separate candidate rank from acceptance. Fail closed on incompatible, absent or unknown metadata. Keep original rank/score intact; permit only explicit validated score-domain adapters. Refit/validate calibration after relevant changes. No numeric thresholds approved.
