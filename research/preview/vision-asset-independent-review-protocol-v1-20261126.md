# Vision asset independent review protocol v1.0
2026-11-26 JST. Proposed preregistration before receiving anonymized artifacts. No approval of recognition performance thresholds or actual holdout admission.
G0: Verify exact expected file names and sender-calculated SHA-256 of original artifacts before opening/processing; ZIP outer then inner digests before reading contents; name differences allowed only with complete hash match. If mismatch/absent expected digest stop. Reject archive unsafe paths, unexpected entries, secret/identifying/raw image data; no external transfer of original images, credentials or private mapping. Privacy review not established by hash or pattern scan.
G1: Original JSON and MD required; check schema, 376 unique candidate content rows vs prior report, IDs, counts, references, enum mapping and explicit null/unknown. No silent repair. Actual original schema unknown; produce documented deterministic normalized projection (only fields required by v2, no free text), hash it, preserve source, review dropped evidence fields separately. Code does not directly parse original Muse schema or ZIP/MD.
G2: Recompute from per-content records: reported 390 index entries, 412 local matches, 376 content, 31/167/58/113/7 scene counts, 22 direct and 231 related-inclusive vs 145 candidate, 17/13 battle groups, 22/354 label counts. Prior values are comparison not required target; unexplained discrepancy fails, justified correction allowed. Reconcile content_copy_count definition separately and compare original report totals. Compute A–E per PV/OCR and include null battle bucket. D=declared full six label count; D_screen_rights_declared is stricter and neither proves actual eligibility. Compare aggregate declarations with recomputation; confirm positive verified scene and labels, no rights unknown.
G3: Recompute connected components from same battle/source/group links, per PV/OCR plus reference usage; used or unknown linkage blocks candidacy. Count components rather than raw images or nominal battles if linked. No known usage != proved independence. Require documented complete scope of previous usage records, near-duplicates/recording lineage, no concealed linked groups, evidence of group assignment; incomplete => conditional review, not holdout. Separate PV and OCR; reference overlap blocks conservative candidate status in both.
G4: Inspect original declared 12 sample rows, sample selection, 2 corrected errors, whether all selected previews and label evidence verified locally with classifier-independent procedure. Proposed local verification of all candidate preview frames (at most 31 reported) and representative negative frames; no external raw images. Partial labels may support separate tasks but not full-six correctness. 12 sampled frames do not establish population accuracy.
G5: Asset inventory pass separate from candidate eligibility and final recognition acceptance. Candidate admission requires scene verified, independent labels, rights, independent component and frozen split; unknown => quarantine. OCR labels must match exact target region/event not just species slots; v2 D is preview-specific, no OCR content validation. Freeze recognizer/config/dictionary/thresholds before independent outcome; no tuning on holdout. Quantitative acceptance policy separate user approval; 13 independent groups with zero errors still one-sided 95% upper bound 20.6% (only if representative independent groups); no claim all 13 contain preview. No recognition performance established.
