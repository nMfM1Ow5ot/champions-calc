## Method and results
V2 retains full canonical image. Native aspect normalization or centered full-height 16:9 viewport hypothesis, not arbitrary crop/localization. On v1 layout failure estimate a common signed vertical boundary displacement from >=5 of six rows, then evaluate two signed horizontal edges at vertically corrected positions; consensus tolerance 1px, default search ±24px in canonical coordinates. Inverse integer translation then require complete v1 layout recheck. Already passing v1 images are not shifted (not exact registration). Flat-patch test: mean per-channel standard deviation <2 in sprite interior or overlapping 12x24 subwindows, and large central region. Threshold explored .1/.5/1/2/3/4; 4 rejected 3/29 positives; 2 chosen in development, no independent threshold validation. Initial unsigned row edges failed correction; signed vertical edges alone plus horizontal estimate recovered 201/232; y-conditioned signed horizontal edges recovered 230/232. 
Linux x86_64 OpenCV 4.13.0 NumPy 2.3.5, configured one thread. 29 known normal and 2 actual incompatible static images plus deterministic transformations. Synthetic 1920x1080 centered embedding (1646x1080 resized from canonical, black side margins) is an explicit test domain, not representative original video.
