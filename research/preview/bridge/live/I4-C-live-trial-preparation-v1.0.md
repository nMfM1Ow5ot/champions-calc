Duplicate snapshot keys held, no producer lock or atomic publication proof; not an adversarial filesystem security claim. Fresh mtime is a proxy, not capture sequence. Poll every 0.5 s plus processing; newest-only sampling can miss ring frames. Old OCR/recognition runs on sample before asynchronous new offer, one in-flight worker, busy/disabled accounted. Compare normalized ASCII ID strings only, not canonical form equivalence or accuracy. New path also sees old-negative samples. Full stateful legacy votes/lock, actual consumed-frame equality, end-to-end production latency/total dropped-frame rate and production noninterference under load remain untested. 
Bounded run: 90 s / up to 60 sampled frames; 140 s external watchdog (includes startup), controlled Enter after compilation. Resource ps samples parent/descendant tree only; CPU ps estimate, summed RSS may count shared pages twice. User submits aggregate only. Local 0700 directory holds private-pairs.json (lineups, hashes, old and new candidates) and aggregate.json. No raw snapshot retention by observer beyond transient worker spool under normal completion; abnormal cleanup not guaranteed. Normal stop retains actual owned Process, drains queue, terminates and checks exit, removes private spool. On timeout/interrupt supervisor signals verified current descendants of its own live process, then its own Popen only; no arbitrary process group kill, no automatic kill of unverifiable reparented PID. Observed PID presence is conservative diagnostic, not identity proof.
