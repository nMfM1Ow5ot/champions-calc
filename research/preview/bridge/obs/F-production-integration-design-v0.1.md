## FI-02. IPC contract proposal v1
ADR: choose reader-owned persistent Python child over per-frame launch or reuse of Paddle spool. Alternatives: UDS (more lifecycle/security complexity), file spool (easy recovery but disk IO/stale files; existing shadow evidence only), stdio framed pipe (simple lifetime, no ports, no image files). Select stdio framed pipe, no shell, no external network, dedicated bounded queues, child stderr drained and redacted, stdout exclusively protocol. One in-flight and one latest pending frame, replace pending only; drop counted, never block capture queue. Reader snapshots immutable CGImage and encodes lossless PNG, correct color/orientation/stride tests; no reuse of rotating file paths. Submit from decoded handoff before existing OCR; shadow can evaluate valid eligible positive and negative frames, even OCR misses. No duplicate capture. Separate candidate task; read ready result at matching frame decision point; never await indefinitely or use later frame result as current. In shadow no state effects whatsoever.
Frame wire format: 4-byte unsigned big-endian header byte count (1..16384), UTF-8 JSON object, then exactly payload_bytes raw bytes (0..16777216). Read exactly, reject duplicate keys/NaN/Inf, unexpected keys/types/oversized lengths/partial EOF; monotonic timeout on whole message, no resync after malformed frame, close child. Ready/control/response payload_bytes=0. Request fields: schema=champions-preview-ipc-v1, kind=analyze, launch_uuid, session_epoch (increment at capture discontinuity/new session), frame_seq (integer >=0 unique per launch), request_uuid, captured_monotonic_ns (decimal string), source_id (enumerated quicktime/obs/replay), width,height (1..4096, total <= 4096*4096), encoding=png, payload_bytes, frame_sha256, release_digest, asset_digest. Verify PNG magic/IHDR dimensions before decode, actual decoded dimensions and uint8 BGR, digest mandatory. Reject overflow, no filesystem paths transmitted. Reader computes deadlines with monotonic clock, worker echoes identities not timestamps as trust. Ready echoes protocol/release/assets/calibration/score kind, process instance; request only after verified ready. Response fields exact request identity/digests + result (unmodified F object) + elapsed_analysis_ms; error uses enum with null result, no exception text; held retains F result; verify route/status invariant, 6 slots, max5 distinct known IDs each ordered finite nonnegative distance and deterministic tie, type tokens/order, recovery booleans, accepted/scene_authenticated always false. Require exact request tuple, same source, epoch, current frame, session and release; reject replay/stale/duplicate and cross-session response. No response is a hard observation. Clear in-flight/latest on boundary; terminate own child on protocol breach/timeouts, drain pipes, no PID adoption/global kills. Child exits on EOF, bounded TERM then KILL by owned Process, reader restart42 cleanup; no busy retry. Proposed initial test budgets: ready <=10s, whole frame round-trip <=250ms, one restart per 30s max 3 per session then disable until next session; provisional not measured, FI-07 revise using replay/load results, no threshold tuning on holdout. If asynchronous result unavailable, old path continues unchanged. Never serialize raw frames into production logs. Metrics counts, wall times, resource, no labels/images/private paths in exported report.
