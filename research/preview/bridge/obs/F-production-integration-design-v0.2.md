## R1-A. C-01: identity, acquisition and decision
Identity A=(launch_uuid,capture_generation,frame_seq,frame_sha256,source_profile_id). launch_uuid fresh per reader instance, generation increments on capture discontinuity, restart, source/profile change, sleep/clock ambiguity, explicit invalidation; frame_seq monotone within launch (never reset on generation); hash of exact transmitted PNG; separate immutable decoded-frame provenance and source profile. A is transport identity, never a battle identity. For pre-OCR submission, request has NO semantic session ID. Authority on existing serial recognition queue binds immutable A to S=(launch_uuid,semantic_session_seq), only after existing phase transition plus explicit trusted boundary decision. Bind once; unknown/ambiguous scene => no binding, no F acceptance. If source generation changes, session authorization becomes suspended and old candidates invalidated, but verified battle facts remain. A result cannot create S, rebind A, or establish scene truth. No independent use of F gate as scene authentication. Capture source/size/profile fixed per experiment; different profile separate validation. Shadow does not alter any legacy transitions, including OCR miss.
Sequence: snapshot eligible decoded image (own reference, not rotating path) -> optional async shadow submission -> legacy OCR/phase decisions -> create/bind S for that frame if warranted -> consume validated result only in that frame's decision window -> close A. Pending after window closes may be logged as late for diagnostics, never applied. In shadow results may arrive after legacy frame completes, still linked to A only for evaluation; no state writes. In future f mode define bounded join on the recognition queue, outside locks, with capture producer independent. Expiry of frame/session/generation, source switch, cancel/end/new preview, manual start, reader restart invalidate old apply token before new binding. A new session cannot inherit pending candidates, votes or engine choice. Stable frame dedup is transport identity and content identity, neither implies statistical independence. Duplicate A/result or same content contributes no second corroboration. Legacy signature skip/blank/resume/queue drop recorded as distinct exclusions, not recognized positives. Debug, team registration, one-shot, capture-test stay legacy until separately specified. Replay receives synthetic monotonic acquisition sequence and explicit source profile; no real capture. Counters include eligible/skip/admitted/replaced/expired/ranked/held/error/late/consumed; each offered frame has terminal outcome (late response auxiliary count). State effects confined to authoritative queue.

## R1-B. C-02: versioned candidate state and withdrawal
Never map F results directly to PvSlotInfo, decisive flag, previewVotes, previewLocked, oppReset, oppTeam or legacy failure/reset path. A held/error is absence of F evidence, not non-preview, new battle or reset. Existing code (reader 11165–11243; UI 3923–4015) compacts slots and can ignore empty/subset team while retaining old inference. Existing oppUnconfirmed is not sufficient retraction. Shadow outputs external to served/log-upload paths; no new UI schema needed for shadow. Future f mode requires separate approval of versioned producer/consumer protocol and acceptance policy; if not implemented, f unavailable.
State machine for future f (proposal):
| State | Trigger | Next / effect |
|---|---|---|
| idle | independently established new preview session | collecting; reset only candidate layer for new S |
| collecting | same-frame valid F result + approved acceptance policy | collecting; provisional candidate revision |
| collecting | publish authorized, coherent consumer ready | provisional_published; full snapshot, not hard truth |
| collecting | timeout/error before publication | legacy_session; no F state effects; legacy for whole S |
| provisional_published | corrected or stronger evidence | provisional_published; new complete revision supersedes old |
| provisional_published | worker loss, invalid provenance, unresolved conflict, capture gap | withdrawn; revoke affected F hypotheses; preserve observed/user facts; recompute |
| withdrawn | current battle continues | observed_only; no fallback mixing; legacy eligible at next verified boundary |
| any active | verified field observation or user correction | update separate fact/correction layer, invalidate dependent provisional hypotheses; no implicit user correction as observed truth |
| any active | verified session end/new boundary | closed; reject old responses, release session engine selection |
| closed | independently established new S | collecting or legacy_session according to preflight |
Session mode selected before first publish; cannot toggle mid-session. Phase ambiguity suspends F application; never starts new session from F. Confirmed observations are only authorized existing evidence, not simply top1 or two matching frames. User corrections tracked separately, with explicit conflict resolution; do not overwrite verified battle events. No locking based on F scores/types/temporal agreement. Full six ordered slots, including nulls and unresolved candidates; species clause family conflict => unresolved, not forced alternative. Preserve self team, HP, trainer, field, battle events and own recognition; own-preview branch decoupled only in approved f implementation; legacy behavior unchanged.
Future snapshot schema preview-hypotheses-v1 (conceptual): release_set_id, S, revision (strictly increasing within S, decimal UInt64), supersedes_revision or null, disposition=provisional/withdrawn/closed, six slots (null or exact candidate ID + provenance A + acceptance-policy ID), observed_refs, user_correction_refs, active_revision_digest. Full authoritative replacement including all-null and withdrawal; observed_refs and user refs not fabricated by candidate worker. Single writer atomically replaces snapshot; stale/duplicate revisions ignored; same revision different digest => fault, disable candidate layer. Consumer must atomically replace candidate layer, retract old dependent inference, recompute from unchanged confirmed evidence plus approved remaining soft hypotheses, publish output tagged same S/revision/digest. Missing/invalid/unknown/mismatched snapshot or incompatible consumer => candidate inference unavailable, NOT preserve stale F guesses or convert into hard constraints. On restart clear old candidate layer before accepting fresh validated current snapshot; no reliance on legacy oppTeam empty-array semantics. Reader can continue verified observations independently. Before enabling f, require consumer capability handshake and explicit revision acknowledgment (or demonstrated equivalent) with bounded deadline; no ack => withdraw, disable F and display unavailable, consumer TTL/invalidation fail closed; timeout/liveness budget defined and approved at FI-05/07. Raw candidates never become hard legality constraints; only approved uncertainty representation or exclude F from inference. UI schema, TTL and consumer implementation not authorized now. Test consumer replay/restart, empty/partial replacement, stale/duplicate, false candidate after publish, correction, fault before/after, no loss of facts, no repeated oppReset.

## R1-C. I-01: wire contract proposal v1.1
Transport: reader-owned long-lived child, binary stdin/stdout (no shell, no ports, stderr separate bounded drain). Framing 4-byte unsigned BE JSON header length 1..16384, strict UTF-8 JSON object then exactly payload_bytes raw bytes (0..16777216). Header no BOM, duplicate keys, extra keys, NaN/Inf, unpaired surrogate, trailing JSON or wrong scalar types; validate before allocation; integer token syntax decimal, reject bool-as-int. IDs lower-case canonical UUIDv4 for launch/request/worker, lower-case 64 hex for digests, bounded ASCII enums; sequence/generation and monotonic ns decimal strings canonical UInt64 (0 or nonzero without leading zero), avoid JSON number precision loss; fail before wrap. Scores finite numeric >=0 (bool not allowed), no probability claim. Field set exact:
- common: schema=champions-preview-ipc-v1.1, kind, payload_bytes, release_set_id (SHA256), worker_uuid (child-generated instance UUID after ready; expected instance after handshake).
- ready: common + launch_uuid, asset_digest, calibration_digest, mapping_digest, score_kind=joint25-dynamic-gallery-recovery-v2, status=ready; payload_bytes=0. Parent supplies launch UUID and expected release manifest via verified local launch args/environment; independently verifies ready vs local trusted manifest, not trust child self-report alone.
- analyze: common + launch_uuid,capture_generation,frame_seq,request_uuid,captured_monotonic_ns,source_profile_id (ASCII [a-z0-9_-]{1,64}, exact manifest allowlist), encoding=png,width,height (int 1..4096; <=16777216 pixels), frame_sha256,asset_digest; payload_bytes 1..16777216. No semantic session or file paths. Parent admits only after valid ready; child checks identities and manifest. PNG magic/IHDR width/height, bounded dimensions, reject unsupported encoding, actual decoded shape/dtype uint8 BGR, mandatory digest. Do not decode unbounded image. Encoding lossless preserves image content; color/orientation verified on fixtures, no resize.
- result: common + all analyze fields except encoding,width,height,payload_bytes (payload_bytes=0), result (unmodified frozen F object), elapsed_analysis_ms finite >=0. Echo request identity, source, capture ns, digest, asset digest exactly; parent checks all fields against outstanding request. F schema pv16-pv11-hybrid-research-v1; exact keys schema,route,reason,status,accepted,scene_authenticated,slots,types,recovered. accepted=false and scene_authenticated=false. ranked route full (reason full_layout_candidate) or pv11_fixed_visible (reason pv11_layout_0/1; confirm actual index at implementation); six slots each null or nonempty list <=5 distinct reference IDs (manifest list), score ascending then lexical ID; types six pairs tokens from 18 types,NONE,UNKNOWN, recovered six bool, true requires nonnull rank. held route held, all slots null, types/recovered null, reason in frozen reason set invalid_input/explicit_visibility_rejection/pv11_unsupported_resolution/pv11_no_unique_layout/invalid_panel_bounds/sprite_flat_patch. No scene-authenticated claims. Unknown or invalid values => protocol fault.
- error: common + same identity echo as result, error_code enum decode_error/asset_error/analysis_error/contract_error, payload_bytes=0, result absent; no exception text or paths. If request cannot be parsed/identified, no guessed error identity; close transport and parent observes fault. shutdown by EOF; no extra control frame in v1.1. Ready error before handshake => exit, not ready.
Single in-flight A and latest pending decoded image (replace pending only; release replaced copy); no encoded backlog. Dedicated bounded IO and encode queues; nonblocking/select or bounded cancellable writes/reads, exact lengths; no resync after framing fault. Time starts at admission, includes encode, queue residence, write, decode, analysis, response read; capture-to-decision age measured separately from admission. Pending item expires if deadline passes, never start stale work. Initial mock-only proposals (not production acceptance): 10s ready, 250ms admission-to-valid-response hard deadline, 500ms capture age ceiling in same clock domain, <=1 restart/30s and <=3/session, stderr ring 64KiB and anonymous counters, no raw frames persisted. At most two admitted frame references (4 bytes/pixel <=64MiB each), one encoded PNG <=16MiB, header <=16KiB; encoder/decoder scratch, child arrays, OS pipes and native libraries additional, not claimed total RAM bound; measure RSS and bound via separate resource gate. No image copy work on capture queue; don't schedule duplicate encode. Watchdog independent of blocked IO, close descriptors on cancellation, terminate owned child then bounded escalation/reap; parent-crash cleanup requires independent supervisor/OS proof, EOF alone not sufficient for native hang. Do not adopt PID from stale file or kill by port. If cannot prove cleanup on Mac, real-worker rollout blocked. Timeout not p95 SLA; record p50/p95/p99 including failures separately with denominator; no hidden retries on same A. FI-05 must test partial header/payload/EOF, oversized/duplicate/invalid JSON, stalled writer/reader, stderr flood, native hang, parent crash, late/duplicate/cross-session, queue pressure and cleanup. Final resource thresholds require approval after baseline measurements; mock limits not optimized on holdout.

## R1-D. C-03: coherent release and synchronization
Define release-set manifest covering launcher/reader/serve/UI/data/worker/transitive code/dependency environment and profile/mapping/calibration/asset digests, protocol and acceptance policy, compatibility matrix. Compute release_set_id=SHA256 of exact immutable manifest bytes (exclude its own ID); verify against separately trusted approved digest, not mutable branch or self-described manifest. Private manifest and assets stay local, no credentials/logs/raw corpus in public repository; no automatic installation. Use verified exact bytes, versioned immutable dirs with private permissions, no in-place mutation by sync. Read-only permissions alone do not defend against malicious same-account changes; validate at preflight, enforce no concurrent writer by ownership/locking and verify actual loaded set. Preserve local config separately, explicit schema and migration with rollback; no overwrite of user settings.
Transaction: PRECHECK (before any port stop/sync; verify local launcher and dependencies, mode permission, storage, existing process ownership) -> STAGE new release outside active tree -> VERIFY all hashes/dependency ABI/profile, start isolated readiness/consumer handshake without state publication -> READY -> COMMIT only at verified idle boundary with no active battle, pending events/updates or F request, old processes stopped/reaped; atomic local pointer replacement on same FS; start coherent set, each participant verifies same release_set_id/protocol and readiness before publishing. Crash before commit leaves old pointer; crash after commit but before successful readiness => revert pointer to previous verified set at safe idle, otherwise fail closed and require operator recovery. Retain old full release and Mac archive, journal stage/previous/new IDs and outcomes; no force push/reset or unverified remote sync. No activation during ongoing battle or ambiguous phase. Reader exit42 alone not proof of idle; require explicit safe boundary and controlled supervisor; ordinary legacy path remains unchanged until separately approved. Server background repair/self-exec, sync_ui.py, log upload, UI auto reload must respect frozen set or be disabled for research; legacy main code does not yet implement this. Research R3 uses no original launcher/server, no port 8765, no sync/uploads, isolated paths and environment; prove actual noninterference before real worker. Mode negotiation: legacy default no F import; shadow explicit and no state publication; f disabled by default and fails preflight without approved policy and compatible producer/consumer. No automatic downgrade in a published session; withdraw candidate layer, preserve evidence, choose legacy next boundary. Old runtime actual restore not yet verified; must test coherent offline restoration before deployment.

## R1-E. C-04: preregistration template (not a final threshold decision)
Population: selected M-C doubles capture profile(s) with actual source provenance, positive preview and negative/non-preview, usual and PV11 route; source/route strata reported, route defined by frozen algorithm (not hand-picked after scores). Independent unit is battle or recording lineage cluster; exclude all development/adjustment/calibration/dictionary use and linked clusters per v1.1, including known 7 overlaps; unknown independence not eligible, user rights and independent labels required. Freeze code, bank, calibration, mapping, acceptance policy, profile, cohort and evaluation code before labels scored; unknown label slots excluded transparently; full six requires all six labels, exact form distinct. Negative truth is independent scene label; held is not scene classification.
Primary safety metrics: cluster-level probability of >=1 false published/accepted candidate (including wrong scene, wrong slot/form, stale session, duplicate family, unsupported ID) and false publication on negative clusters; report separately. Independent correctness/coverage: Top1/3/5 on all known truth slots with held/drop/timeout as misses, accepted precision and coverage separately (zero accepts => precision undefined), exact and base normalized separately, six-slot complete with all known labels, no forced ID, per route/source. Raw rank candidate errors are not publication errors. Compare paired old/new on same eligible frames/clusters, include misses and all offer/skip/drop accounting; report cluster dependence and uncertainty, no frame/slot independence assumption, no aggregate route masking. Resource and noninterference: capture-to-decision age, admission/encode/queue/IPC/analysis, deadlines and failures, CPU/RSS/swap, state/event equality in shadow with declared timestamp normalization only, no lost critical frames or unsafe writes. Zero cross-session application, unapproved state write, mixed release, data exfiltration, confirmed-fact loss, uncontrolled orphan and invalid protocol acceptance are deterministic test invariants (not statistical guarantees).
Before evaluation user approves risk bound epsilon, confidence 1-alpha, minimum coverage c, accuracy noninferiority margin, latency/resources and per-stratum target counts/stop rule. For zero observed errors in n independent representative Bernoulli clusters, one-sided exact upper bound 1-alpha^(1/n); to make bound <=epsilon require n>=ceil(log(alpha)/log(1-epsilon)). For nonzero failures use exact binomial interval when independence/representativeness plausible; clustered/paired analysis by battle, not arbitrary pooling. If no representative sample or too few clusters, report descriptive result only; no extrapolation. Multiple primary strata require prespecified multiplicity control or explicitly separate claims. No final numerical thresholds or sample counts selected; plan must be approved and feasible against existing resources. No sequential optional stopping; fixed cohort/size, or separately approved valid sequential plan. No holdout-driven tuning. Current independent admission=0; no new test or approval inferred. f remains disabled if gate cannot be met, shadow may continue only within separate approval and prerequisites. Seven reference result 42/42 overlap and 659 regression equivalence remain reference/regression only.
